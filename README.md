# Blackjack Strategy Trainer

A single-page trainer for blackjack basic strategy. It covers when to hit, stand, double, split or surrender.

- **Drill**: deals random hands. You pick the play and get the right answer with a short reason. Keys: H / S / D / P / R, then Space for the next hand.
- **Focus on my mistakes**: hands you've missed recently come up more often.
- **Chart**: the full strategy chart, with your accuracy on each spot. Table rules can be switched here (H17/S17, double after split, surrender).
- **Learn**: the rules of thumb behind the chart.

The default rules are 6 decks, dealer stands on soft 17, double after split, and late surrender.

It is a static page with no build step. Open `index.html`, or host it on GitHub Pages.
